# DataFrame Experimentation with Pandas

This repository is used to experiment with and learn the functionality of the Pandas library through hands-on analysis and transformation of a real dataset.

**Project purpose:**
- Learn and demonstrate Pandas core features (reading/writing CSVs, indexing, filtering, groupby/aggregation, joins/merges, reshaping, time series, plotting, and performance tips).
- Use practical examples in a Jupyter Notebook to build intuition and runnable snippets.

**What's included:**
- `1.ipynb` — the primary notebook containing examples, walkthroughs, and the original Kaggle dataset link.
- `archive/` — CSV files extracted from the dataset used in the notebook.

**Dataset:**
The dataset used for these experiments comes from Kaggle. The original dataset link and attribution are provided inside `1.ipynb` — open the notebook to view the exact Kaggle source and licensing information.

**Getting started:**
1. Create and activate a Python environment (recommended).
2. Install minimal dependencies:

```bash
python -m pip install pandas numpy jupyter
```

3. Open the notebook in VS Code or Jupyter to follow the examples:

```bash
jupyter notebook 1.ipynb
```

**Notes:**
- This repo is for learning and experimentation; feel free to modify the notebook and try different Pandas techniques.
- If you plan to redistribute derived data, check the original Kaggle dataset license in `1.ipynb` first.
